# Спецификация онлайн-калькулятора



Онлайн-калькулятор позволяет пользователю выполнять основные арифметические операции с двумя числовыми значениями и получать результат.



Пользователь вводит два числа в соответствующие поля ввода, выбирает одну из доступных арифметических операций («+», «-», «\*», «/») и нажимает кнопку «Вычислить». После нажатия кнопки «Вычислить» результат выбранного действия отображается в поле «Результат».



Например, если пользователь вводит в первое поле значение 10, во второе поле значение 5, выбирает операцию «+» и нажимает кнопку «Вычислить», в поле «Результат» отображается значение 15.



##### Ввод чисел



Пользователь вводит значения в поля ввода. Значение может быть целым или дробным числом. В поле ввода разрешены цифры, символ «-» для обозначения отрицательного числа и символ «.» для ввода дробных чисел.



Если результат является дробным числом, он округляется до двух знаков после запятой.



Если введённое значение не соответствует формату числа, поле ввода подсвечивается как ошибочное, а выполнение операции становится недоступным.



##### Поле «Результат»



Поле «Результат» не редактируется пользователем и отображает результат выбранного действия. Значение в поле появляется только после нажатия кнопки «Вычислить».



##### Арифметические операции



Кнопка «+» выбирает операцию сложения.



Кнопка «-» выбирает операцию вычитания.



Кнопка «\*» выбирает операцию умножения.



Кнопка «/» выбирает операцию деления.



###### Кнопка «Вычислить»

выполняет выбранную операцию над двумя введёнными числами и отображает результат в поле «Результат».



При выборе другой арифметической операции ранее выбранная операция заменяется новой. Результат вычисления при этом не изменяется до нажатия кнопки «Вычислить».



###### Кнопка «Удалить»



Кнопка «Удалить» очищает оба поля ввода и поле «Результат». После нажатия кнопки все введённые значения удаляются.



###### Продолжение вычисления



Кнопка «Продолжить вычисление» доступна после получения результата.



При нажатии кнопки значение из поля «Результат» переносится в первое поле ввода. Второе поле ввода и поле «Результат» очищаются. Выбранная арифметическая операция сбрасывается.



После этого пользователь может ввести второе число, выбрать новую операцию и выполнить следующее вычисление.



##### Ограничения и ошибки



Кнопки арифметических операций и кнопка «Вычислить» недоступны, пока оба поля ввода не содержат корректные числовые значения.



При попытке деления, где одно из значений равно 0, пользователь получает системное сообщение: «Деление не может быть выполнено».



##### История вычислений



После успешного вычисления полное выражение и его результат добавляются в историю. Например: «5 + 3 = 8».



История содержит все успешные вычисления пользователя за текущие сутки.



При наступлении новых суток история предыдущего дня очищается.



Новые сутки определяются по локальному времени пользователя.



### Backend API

###### 1\. Получение истории вычислений



Метод: GET

Endpoint: /history



Успешный ответ: HTTP 200 OK



Возвращается список вычислений пользователя за текущие сутки.





|Поле|Тип|Обязательное|Описание|
|-|-|-|-|
|history|array|Да|Список выполненных вычислений|
|history\_expression|string|Да|Полное выражение|
|history\_result|number|Да|Результат вычисления|



**Пример ответа:**



{

&#x20; "history": \[

&#x20;   {

&#x20;     "expression": "5 + 3",

&#x20;     "result": 8

&#x20;   },

&#x20;   {

&#x20;     "expression": "8 \* 2",

&#x20;     "result": 16

&#x20;   }

&#x20; ]

}



Если вычислений за текущие сутки нет, сервер возвращает пустой список.



**HTTP 200 OK**



{

&#x20; "history": \[]

}



###### 2\. Выполнение вычисления



Метод: POST

Endpoint: /calculations





|Поле|Тип|Обязательное|Описание|
|-|-|-|-|
|firstNumber|number|Да|Первое числовое значение|
|secondNumber|number|Да|Второе числовое значение|
|operation|string|Да|Арифметическая операция:<br />(+, -, \*,/)|



**Пример запроса:**



{

&#x20; "firstNumber": 5,

&#x20; "secondNumber": 3,

&#x20; "operation": "+"

}



Успешный ответ



**HTTP 200 OK**

{ "result": 8 }



###### 3\. Ошибки



**Деление на ноль**



Если значение secondNumber равно 0, а operation имеет значение /, вычисление не выполняется.



HTTP 400 Bad Request



{

&#x20; "error": "Деление не может быть выполнено"

}

**Некорректные данные**



Если отсутствует обязательное поле, передано значение неправильного типа или указана неподдерживаемая операция, вычисление не выполняется.



HTTP 400 Bad Request



Пример:



{

&#x20; "firstNumber": 5,

&#x20; "secondNumber": 3,

&#x20; "operation": "%"

}



Ответ:



{

&#x20; "error": "Некорректные данные запроса"

}

###### Продолжение вычисления



При нажатии кнопки «Продолжить вычисление» запрос на сервер не отправляется.



После ввода второго значения и выбора новой операции фронтенд отправляет обычный запрос POST /calculations.



Например, после вычисления:



5 + 3 = 8



пользователь нажимает «Продолжить вычисление», вводит 2 и выбирает \*.



Фронтенд отправляет:



{

&#x20; "firstNumber": 8,

&#x20; "secondNumber": 2,

&#x20; "operation": "\*"

}



Сервер возвращает:



{

&#x20; "result": 16

}
